# 视觉与交互规范

> 第一版产品叙事、首屏构图与验收标准见 [设计 Teaser](v1/01-design-teaser.md)。

## 设计方向

视觉关键词是“安静的书房”，而不是工具栏密集的效率软件。暖纸色承担大面积背景，墨色负责文字，陶土红只用于进度、播放和高亮等需要被注意的状态。

## 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| Paper | `#F7F1E6` | 主背景 |
| PaperLight | `#FCF8F0` | 卡片与浮动控制 |
| PaperDeep | `#E9DFCE` | 分区与按压背景 |
| Ink | `#252D29` | 主文字与主要按钮 |
| InkSoft | `#58615B` | 次级说明 |
| Terracotta | `#CB6A4B` | 播放、进度、强调 |
| Highlight | `#F1D69B` | 当前朗读句 |
| HighlightStrong | `#E9B968` | TTS 当前词 |

文字与背景保持高对比。高亮不改变正文颜色，避免朗读时视觉跳动。

## 字体

- 品牌、书名与正文：系统衬线字体，强调纸张阅读感。
- 控件、标签与说明：系统无衬线字体，保证小字号可读。
- 正文默认 18sp、约 1.78 倍行距；用户可调到 14sp 至 28sp 的视觉范围。

系统字体策略避免首版打包大体积中文字库，也遵循设备字体缩放。

## 页面结构

书库：

1. 品牌标题与一句产品说明。
2. 搜索栏。
3. 自适应两列或更多列封面。
4. 底部悬浮“导入一本书”。

阅读页：

1. 顶部保留返回、目录和更多操作。
2. 正文四周留白大于普通列表，单页信息密度低。
3. 底部播放条只在需要时出现；隐藏工具栏时保留圆形朗读入口。
4. 正文点击用于定位朗读，空白点击用于显示/隐藏工具栏。

## 交互反馈

- 导入过程显示明确进度态，失败使用可读中文原因。
- 翻页使用短距离横向过渡，不模拟真实翻纸的长时间动画。
- 当前句使用淡金色底，当前词使用更深金色并加粗；PDF 行高亮使用更低透明度。
- 播放、暂停、前后句都保留至少 48dp 点击区域。
- 播放条直接显示当前“女声/男声”预设，切换后从当前句继续。
- 底部弹出层负责目录、快速跳转和排版，避免再叠一层完整页面。

## 兼容与无障碍后续项

- 为图标补齐 TalkBack 描述和朗读状态。
- 支持系统字体缩放，不固定 composable 高度。
- 增加减少动画开关。
- 深色模式计划在视觉基线验收后加入，首版先稳定暖色浅色主题。
- 验证旧版 Android 上的状态栏、导航栏和底部安全区。
