# 设备验收清单

## 当前环境

截至 2026-11-17，本开发电脑只有 JDK 21，没有 Android SDK、ADB、Gradle、模拟器或移动设备。为避免在低配置机器上做无效调试：

- 未启动模拟器。
- 未连接手机。
- 未生成 APK。
- 未执行真机截图。

因此当前结论是“代码基线完成、编译与设备验证 pending”，不能视为可发布版本。

## 第一次在开发电脑上要做的事

Ubuntu 24.04 的完整环境安装见 [Ubuntu 开发与调试指南](ubuntu-development.md)。Windows 与 Ubuntu 都使用相同的 Gradle 任务和测试文件。

1. 安装 Android Studio 最新稳定版、Android SDK 35、Build Tools 和 Platform-Tools。
2. 使用 Android Studio 打开仓库并完成 Gradle Sync；Wrapper JAR 已随仓库提供。
3. 执行 `make portable` 和 `make check`。
4. 执行 `make build`。
5. Ubuntu 额外执行 `bash scripts/ubuntu-doctor.sh`，Windows 可直接由 Android Studio 检查 SDK。
6. 修复所有编译与 Lint 阻断项，再把结果写回 [开发日志](development-log.md)。

## 功能验收

先导入仓库中的 [中文/English 验收样例](../samples/灯塔与纸页.md)。PDF 请准备无版权的单栏、双栏、旋转页和扫描版文件各一份。

### 导入与书库

- [ ] 从“下载”“文档提供者”和文件管理器分别导入 PDF。
- [ ] 导入 UTF-8、GB18030 Markdown/TXT。
- [ ] 取消系统文件选择器不出现错误。
- [ ] 同名文件可重复导入且互不覆盖。
- [ ] 应用重启后书库与封面仍在。
- [ ] 移除书籍后私有目录被清理。

### 文本阅读

- [ ] 中英文长段落没有跨页截断。
- [ ] 字号最大与最小时没有文字溢出。
- [ ] 左右滑动连续跨章节。
- [ ] 目录跳转定位准确。
- [ ] 百分比跳转定位准确。
- [ ] 退出后重新打开恢复到相近页面。

### PDF 阅读

- [ ] 单栏 PDF 正常渲染。
- [ ] 双栏 PDF 文字顺序合理。
- [ ] 旋转页面高亮与文字行重合。
- [ ] 裁剪框非零页面高亮不偏移。
- [ ] PDF 书签转为目录且跳转页码正确。
- [ ] 扫描版 PDF 显示“文字朗读可能不可用”。

### 朗读与高亮

- [ ] 中文系统语音包可初始化。
- [ ] 英文系统语音包可初始化。
- [ ] 女声与男声预设在播放中切换后，从当前句重新开始。
- [ ] 设备存在男/女本地声库时，优先选中名称匹配的声库。
- [ ] 设备只有通用声库时，两种预设仍有可辨识的音高差异。
- [ ] 缺少语音包时有可执行的中文提示。
- [ ] 点击正文可从对应句开始朗读。
- [ ] TTS 支持 `onRangeStart` 时逐词高亮。
- [ ] TTS 不支持词位置时至少有句级高亮。
- [ ] 跨句、跨章自动继续。
- [ ] 播放中打开目录、跳转后状态一致。
- [ ] 暂停后继续不会重复整章。

### 音频导出

- [ ] 短文本可导出单个可播放 WAV。
- [ ] 整本中英文混合书籍可完成导出。
- [ ] 导出文件名和实际音频使用当前选择的女声或男声预设。
- [ ] 长任务锁屏后继续运行。
- [ ] 通知权限拒绝时不崩溃。
- [ ] Android 10+ 文件出现在 `Music/页声`。
- [ ] Android 8/9 文件出现在应用专属音乐目录。
- [ ] 取消/失败后没有残留损坏文件。
- [ ] 多个 WAV 片段格式不一致时给出明确错误。

### 兼容性

- [ ] 普通 Android 手机安装运行。
- [ ] 保留 Android 兼容能力的鸿蒙手机安装运行。
- [ ] 无 Google Play 服务的设备安装运行。
- [ ] 深色系统模式下应用仍可读。
- [ ] TalkBack 可以访问导入、打开、目录和播放按钮。

## 日志记录要求

每轮设备测试必须记录：

- 日期、设备型号、系统版本、Android 兼容版本。
- 使用的测试文件及大小。
- TTS 引擎名称、语言包和采样格式。
- 操作步骤、预期结果、实际结果。
- 截图或录屏路径。
- 失败日志与修复提交。
