# 产品范围与路线图

> 第一版完整设计档案入口见 [docs/v1](v1/README.md)。

## 产品定位

“页声”首先是本地优先的纸质书式阅读器，其次才是有声书工具。用户导入 PDF 或 Markdown 后，可以像普通阅读软件一样翻页、查目录和跳转；开启朗读后，系统语音与正文高亮同步，并可将整本书导出为音频文件。

产品不依赖在线账号、云服务或 Google Play 服务。阅读文件和阅读进度默认只保存在设备上。

## 首个可用版本（MVP）

必须完成的闭环：

1. 从系统文件选择器导入 PDF、Markdown、TXT。
2. 书库展示、搜索、打开、移除；重新打开后恢复进度。
3. 章节目录与百分比快速跳转。
4. 文本类书籍按屏幕实际尺寸分页，支持横向翻页。
5. PDF 以原始版面阅读，目录读取 PDF 书签。
6. 系统 TTS 播放、暂停、前后句与语速切换。
7. 文本类书籍提供句级/词级同步高亮；PDF 提供页内行高亮。
8. 后台合成并合并为单个 WAV 文件。

以上代码已铺设，但“完成”以 [设备验收清单](device-qa.md) 全部通过为准。

## 明确不做的事（当前阶段）

- 不做账号、云同步和社交书架。
- 不接第三方收费语音服务；先充分利用系统 TTS。
- 不首版支持 EPUB、MOBI、DOCX。
- 不承诺扫描版 PDF 可朗读；OCR 是独立里程碑。
- 不复制 Kindle 的 DRM 或受保护电子书格式。
