# 灯塔与纸页

作者：页声示例

这是一份用于开发验收的示例文稿。它同时包含中文与 English，便于检查目录、分页、分词、朗读和音频导出。

## 一、清晨

清晨五点，海雾还没有散。灯塔立在很远的地方，像一枚被遗忘的句号。林舟把书摊在窗边，纸页被风轻轻掀起，又安静地落回原处。

他读到一个很长的句子：人们总以为声音是从远处传来的，可有时候，声音只是让眼前的文字忽然有了方向。于是他停下来，听见潮水、听见屋檐滴水，也听见自己的呼吸。

> 阅读不是把书翻快，而是让某一页愿意为你停留。

## 二、English Notes

The lighthouse was still visible through the fog. It was not a destination, only a reference point that made the coastline easier to understand.

This sentence is deliberately long enough to exercise wrapping, pagination, sentence boundaries, and the 3.14 decimal rule. It should remain readable when the font size changes.

## 三、归途

傍晚，林舟合上书。目录里只有三个小标题，可这一天的阅读比想象中更长。他把书放回书架，决定下次从“归途”继续。

### 尾声

海雾散开之后，灯光没有变得更亮。只是这一次，他知道光从哪里来。
